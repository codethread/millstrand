The live boundary is source and module configuration already visible to the running generation. Edits to `init.clj`, `init.local.clj`, or declared `:ns` and `:file` source can refresh in place while the candidate basis fingerprint is unchanged. An edit to `deps.edn` or `deps.local.edn` crosses the generation boundary. Refresh then returns `:restart-required` before evaluating staged activation, and only Mill's replacement flow can adopt the new basis.

`make test-restart-acceptance` adds the process-level `TestDisposableWeaverRestartAcceptance` proof for replacement custody and continuity. The final release record reports that command passing at the same Millstrand marker. These restart checks support the adoption path in `DNS-S9-06`; they do not broaden the S9 matrix into new retry, fallback, rollback, or compatibility behavior.
