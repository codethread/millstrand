## PLAN-Lrc-001.P1 Goal and scope

Carry the pull request number from `push-draft-pr` completion into the land merge continuation, address the exact PR in the mechanical gate, and add a context-preserving revise route at sign-off. The [proposal](./proposal.md) owns the product boundary.

## PLAN-Lrc-001.P2 Approach

- **PLAN-Lrc-001.A1:** Extend the existing declared `land complete` arg-spec with a positive integer flag. The wrapper passes context only while the ready frontier contains `land.pr.open`, preserving its existing card lane move and rollback behavior.
- **PLAN-Lrc-001.A2:** Add `:pr-number` to the land merge continuation's whole-map spec. Approved and revise routes both use the workflow engine's existing continuation validation before graph mutation.
- **PLAN-Lrc-001.A3:** Replace the merge gate's branch argument with the context PR number. Keep branch-based titles and initial CI behavior because those operate before the PR number enters context.
- **PLAN-Lrc-001.A4:** Exercise the route through the existing config runtime fixtures. Inspect workflow context and gate attributes instead of adding a parallel test harness.
