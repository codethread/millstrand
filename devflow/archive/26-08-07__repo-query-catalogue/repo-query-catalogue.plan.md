# Repo query catalogue plan

**Document ID:** `PLAN-Rqc-001` **Feature:** `repo-query-catalogue` **Proposal:** [proposal.md](./proposal.md) **RFC:** None **Root specs:** [`repl-api.md`](../../specs/repl-api.md) **Feature specs:** None **Status:** Reviewed **Last Updated:** 2026-07-27

## PLAN-Rqc-001.P1 Goal and scope

Reduce the repo-owned named-query catalogue to queries with live consumers, and rename the active workflow-run selector so its name and parameter describe the data it selects.

## PLAN-Rqc-001.P2 Approach

- **PLAN-Rqc-001.A1:** Search current source, docs, scripts, and sibling repositories for each query name before changing the catalogue. The audit must name the consumer for each retained query and state that no consumer was found for each deletion.
- **PLAN-Rqc-001.A2:** Delete unconsumed queries, rename the workflow-run selector without an alias, and update every retained example and test to use the generic `list`, `ready`, and `query` surfaces.
- **PLAN-Rqc-001.A3:** Regenerate the intentional config surface baseline after the catalogue and row-selection tests express the new contract.

## PLAN-Rqc-001.P3 Affected areas

| PLAN-Rqc-001.AA2 | Config tests and surface baseline | Assert the reduced catalogue and the renamed query's row set. |

## PLAN-Rqc-001.P4 Contract and migration impact

- **PLAN-Rqc-001.CM1:** The repo-local query names `feature-active`, `feature-work`, `feature-owner-work`, and `feature-run` disappear. `run-active` replaces the last of these and takes `run-id`.
- **PLAN-Rqc-001.CM2:** The generic named-query registry and batteries CLI contracts do not change, so no root-spec delta is needed.

## PLAN-Rqc-001.P5 Implementation phases

### PLAN-Rqc-001.PH1 Consumer audit

Outcome: Each retained or removed query has recorded evidence from current consumers.

### PLAN-Rqc-001.PH2 Catalogue contraction

Outcome: Config, examples, tests, and the frozen surface agree on the smaller catalogue.

### PLAN-Rqc-001.PH3 Validation and landing

Outcome: Required repository gates and review pass before the branch lands on main.

## PLAN-Rqc-001.P6 Validation strategy

- **PLAN-Rqc-001.V1:** Regenerate the surface baseline and run diff checks first. The test runner rejects a focused cold invocation of `skein.config-test` because it belongs to add-libs shard C, so this slice has no legal focused cold test command.
- **PLAN-Rqc-001.V2:** Run the serialized locked full Clojure suite as the config-test acceptance gate, then the Go, smoke, external spool-suite, dashboard, formatting, lint, reflection, and docs gates required by `AGENTS.md`.
- **PLAN-Rqc-001.V3:** After landing and runtime pickup, inspect `query list` and `query explain run-active` to confirm live discovery.

## PLAN-Rqc-001.P7 Risks and open questions
